# Changelog

## 2.0 — 2026-11-17
First version where this repository holds the complete source. `src/` is the single source of truth; `index.html` at the root is generated by `python3 build.py` and is what GitHub Pages serves.

AI Engineering deck review (22 → 23 cards), based on a combined review of DORA 2024–2025, industry reports and engineering case studies (2024–2026). Card granularity follows the original Eficode deck: one step per change or release, with its own time and position in the sequence.

- Removed: *Agent Tracing & LLM Observability* (infrastructure, not a step) and *Agentic Failure Triage* (cross-cutting, no position in the sequence). Both are kept as hidden `RETIRED_CARDS` so boards saved with them still load.
- Rewritten: *Coding Agent Proposes Change*, *Agent Output Guardrails*, *AI Artifact Change (Non-Commit Trigger)*, *AI Code Review*, *AI-Generated Tests*.
- Renamed: *Online Evals & Drift Detection* → *Post-Release Online Evals* (per-release check, new text).
- Added: *Pipeline & Agent Permission Scan* (1 min, automated), *Automated Release Policy Check* (1 min, automated) and *Mutation Testing* (30 min, automated).
- Rule A4 no longer mentions tracing.
- Review findings: the production-feedback warning now asks for *Post-Release Online Evals*; a warning appears if *Automated Release Policy Check* is not before *Deploy to Production*; *Pipeline & Agent Permission Scan* counts as a cheap fail-fast check.
- Build writes the app to the repository root as well as `dist/`. `config.json` (Supabase URL and publishable key, public by design) is part of the repository.
- Tests: engine tests for the new deck; the UI test skips the rooms screen and ignores network errors when Supabase is not reachable; the engine test skips `test/user-case.json` if it is missing (it was not in the 0.4 package).
- No database changes: `supabase/setup.sql` is unchanged.
